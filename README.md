# A letter to Santa: HTML-in-Canvas demo

A real, accessible `<form>` drawn into a 2D canvas with the
[HTML-in-Canvas API](https://developer.chrome.com/docs/web-platform/html-in-canvas),
waving gently in the snow.

**Live demo:** https://ewewraw.github.io/html-in-canvas-santa/ (Chrome 157+)

Try it:

- Press <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>F</kbd> and search for "puppy".
- Select and copy the text on the paper.
- Tab through the form with a screen reader.

The paper holds still while you hover over it or type, and stays still if you
prefer reduced motion. In browsers without HTML-in-Canvas support, the demo
shows the plain form instead.
